# Components Directory

This folder contains reusable React components for the Financebrocrack application.

## Structure

- **UI Components**: Buttons, Cards, Inputs, etc.
- **Feature Components**: Category cards, Question displays, Answer options
- **Layout Components**: Headers, Footers, Navigation

## Guidelines

- Use TypeScript for all components
- Include prop type definitions
- Follow the established design system in `app/globals.css`
- Use CSS variables for styling consistency
